# Code of conduct

FanPilot follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be kind and patient, assume good intent, and keep discussion about the work. Harassment, insults and personal attacks aren't welcome in issues, pull requests, discussions or anywhere else the project is represented.

## Reporting

If someone's behaviour bothers you, report it with **Report content** in the ⋯ menu of the comment, issue or pull request. Reports are handled privately. The maintainer may edit or remove comments, close threads, and block people who break this code.
